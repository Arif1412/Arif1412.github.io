## ✨ Key Features & UX Highlights

* **Dynamic Cursor Tracking:** Mouse-position light radial glow across hero headings.
* **Modern Micro-Interactions:** Custom hover effects on interactive project cards and skill tags.
* **Sticky Glassmorphism Navigation:** Blur-effect header with smooth internal scrolling links.
* **Responsive Layout:** Fully mobile-friendly layout optimized across devices.
* **Integrated Resume & Contact:** Quick links for direct PDF download and email routing.
